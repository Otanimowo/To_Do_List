# To-Do List Application

A simple command-line to-do list application built with Python.

## Features

- View your to-do list with task completion status
- Add new tasks to your list
- Remove tasks from your list
- Mark tasks as completed or uncompleted
- Data persistence (tasks are saved between sessions)
- User-friendly interface with error handling

## Requirements

- Python 3.6 or higher

## Installation

1. Clone this repository:
```bash
git clone https://github.com/Otanimowo/To_Do_List.git
cd To_Do_List
```

2. Run the application:
```bash
python To_Do_List/To_Do_List.py
```

## Usage

The application provides a simple menu-driven interface:

1. **View To-Do List**: Display all tasks with their completion status
2. **Add a Task**: Add a new task to your list
3. **Remove a Task**: Remove a task from your list
4. **Mark Task as Completed**: Toggle the completion status of a task
5. **Exit**: Exit the application

## Data Storage

Tasks are stored in a JSON file (`tasks.json`) in the same directory as the application. This allows your tasks to persist between sessions.
